# Україномовні шаблони з менеджменту

Колекція HTML-шаблонів українською для вбудовування в Notion: тайм-менеджмент, нотатки, цілі, методології.

## ⚙️ Як це працює

Усі шаблони в цьому репозиторії є **повністю автономними (client-side only)**. Вони не використовують зовнішні сервери чи бази даних.

- 💾 **Зберігання:** Усі введені дані зберігаються виключно в `localStorage` вашого поточного браузера.
- ✅ **Ідеально підходить для:** особистого планування, вбудовування в Notion (через `/embed`), локального використання.
- ⚠️ **Обмеження:** Дані *не синхронізуються* між різними пристроями. Очищення кешу браузера призведе до втрати даних.

## 🚀 Використання

1. Відкрийте будь-який шаблон
2. В Notion: введіть `/embed` → вставте URL шаблону
3. Готово!

## 📱 PWA (Progressive Web App)

Деякі шаблони підтримують PWA — можна додати на головний екран iPhone/Android:
1. Відкрийте шаблон в Safari
2. Натисніть **Share** (квадрат зі стрілкою)
3. Оберіть **"Add to Home Screen"**
